# CodeVault 

> A modern developer productivity dashboard for tracking DSA practice, projects, progress, achievements, and coding growth.

##  About

CodeVault is a web-based developer productivity platform designed to help students and developers organize their coding journey in one place.

The project focuses on combining DSA practice, project management, progress analytics, coding goals, and achievements into a single dashboard.

##  Features

-  Developer productivity dashboard
-  DSA practice tracking
-  Progress and performance analytics
-  Project management
-  Achievement tracking
-  Coding streak tracking
-  Personal development goals
-  Responsive and modern interface

##  Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

##  Project Goals

The main goal of CodeVault is to provide developers with a simple platform to track their technical growth and maintain consistency in coding practice.
